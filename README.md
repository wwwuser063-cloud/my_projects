ACLED Myanmar Conflict Analysis Dashboard ( 2021 - 2025 )

An interactive Power BI dashboard analyzing conflict events and fatalities in Myanmar from 2021 to 2025, utilizing data from the "Armed Conflict Location and Event Data Project (ACLED)".


Project Overview

This project visualizes the socio-political conflict dynamics across Myanmar over a multi-year period. It is designed to help analysts, researchers, and stakeholders understand geographical distribution, temporal trends, and event categories through clean, interactive data visualizations. Data preprocessing and cleaning were performed using Python (Pandas) and Jupyter Notebook, transforming raw data into an insightful analytical dashboard. 


Key Features & Dashboard Components
- Interactive Map Visual:
  Display exact geographic coordinates and concentration of conflict events and fatalities across different regions.
- Fatalities Trend Analysis (Line Chart):
  Tracks the progression of conflict severity categorized by event types from 2021 to 2025.
- KPI Summary Cards:
  Quick-glance metrics showcasing "Total Fatalities (78k+)" and "Total Events (69.9k+)".
- State/Region Slicer (Filter):
  Allows users to drill down into specific administrative regions (Admin1) for localized insights.


Tools & Technologies Used
- Data Source: Kaggle (ACLED Data Feb 14, 2026)
- Data Processing & Cleaning: Python, Jupyter Notebook, Pandas
- Data Visualization: Power BI
- Version Control: Git & GitHub
